# 🚶 BrightWalk

**AI-powered navigation assistant for visually impaired users.**

BrightWalk combines computer vision, location intelligence, and voice interaction to help users explore their surroundings independently — hands-free.

> *"See the world. Hear the way. Walk independently."*

## ✨ Features

- 🗺️ **Explore Nearby** — attractions, restaurants & museums with ratings and distance
- 👁️ **Visual Understanding** — camera-based AI scene description
- 🔊 **Voice Assistance** — spoken instructions and audio descriptions
- 🗣️ **Voice Control** — full hands-free interaction via accessibility services
- 🌐 **Multi-Language Support** — voice output in multiple languages
- ♿ **Accessibility-First UI** — high contrast, large controls, minimal clutter
